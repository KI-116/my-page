
# 🧠 回溯算法学习标签页总结（基于当前页面内容）

## 1. 回溯法是什么（核心定义）
回溯法 = **在集合中进行递归搜索的穷举算法**，本质是暴力搜索，只是可以通过剪枝减少无效分支  

## 2. 回溯法能解决哪些问题

- **组合问题**：从 N 个数中按规则选 k 个  
- **切割问题**：字符串按规则切割  
- **子集问题**：求所有符合条件的子集  
- **排列问题**：强调顺序的全排列  
- **棋盘问题**：N 皇后、数独等



## 3. 回溯问题的统一抽象：树形结构
所有回溯问题都可以抽象为一棵 **N 叉树**：  

- 集合大小 = 树的宽度  
- 递归深度 = 树的深度  
- 终止条件 = 到达叶子节点  

这也是回溯算法能用统一模板解决不同题型的原因。


## 4. 回溯算法模板（重点）
页面给出了完整的回溯模板：  

### **回溯三部曲**
1. **终止条件**：到达叶子节点，记录结果  
   来源：  [当前页](citation-section://1821800646/21)
2. **遍历当前层的所有选择**（for 循环 = 横向遍历）  
   来源：  [当前页](citation-section://1821800646/23)
3. **递归 + 回溯撤销**（递归 = 纵向遍历）  
   来源：  [当前页](citation-section://1821800646/24)

### **伪代码结构**
```
void backtracking(参数) {
    if (终止条件) {
        存放结果;
        return;
    }
    for (选择：本层集合中的元素) {
        处理节点;
        backtracking(路径，选择列表);
        撤销处理结果;
    }
}
```


## 5. 回溯法的效率与局限
- 回溯法并不高效，本质是穷举  
- 剪枝可以减少搜索量，但无法改变穷举本质  
- 之所以使用回溯，是因为这些问题本身没有更高效的解法

页面最后总结了学习重点：  

- 回溯与递归相辅相成  
- 回溯是暴力搜索  
- 回溯能解决的都是难题  
- 所有回溯问题都能抽象为树  
- 模板非常重要，后续题目都基于它

## 🎯 **哈希表理论核心总结（基于你当前页面）**

### 1. **哈希表是什么？**
哈希表（Hash Table / 散列表）是一种**根据关键码直接访问数据**的数据结构，本质上可以理解为“带哈希函数的数组”   
关键码（key）通过哈希函数映射到数组下标，从而实现 **O(1)** 的查找效率  

## 2. **哈希函数（Hash Function）**
哈希函数负责把 key（如姓名）转换成数值索引：

- 先通过 `hashCode` 将 key 转成数值   
- 若超出数组范围，再对 tableSize 取模，使其落入合法区间  

哈希函数的目标是：  
**尽可能均匀地把数据分布到哈希表中，减少冲突。**

---

## 3. **哈希碰撞（Collision）**
当不同 key 映射到同一索引时，就发生哈希碰撞，例如小李和小王都映射到索引 1   

常见解决方法：

### **① 拉链法（Separate Chaining）**
- 每个桶存一个链表  
- 冲突的元素挂在链表后面  
- 需要合理选择 tableSize，避免链表过长或空间浪费   

### **② 线性探测法（Linear Probing）**
- tableSize 必须大于 dataSize    
- 冲突时向后寻找下一个空位存放数据   

## 4. **常见三类哈希结构**
数组、set、map  

### **Set 系列（集合）**  
底层实现与特性如下（来自页面表格）：

- `std::set` / `std::multiset`：红黑树，有序，查询 O(log n)  
- `std::unordered_set`：哈希表，无序，**查询 O(1)（最常用于哈希法）**   

### **Map 系列（映射）**
- `std::map` / `std::multimap`：红黑树，有序，key 不可修改   
- `std::unordered_map`：哈希表，无序，查询 O(1)   
页面特别强调：  
**解决哈希问题时优先使用 unordered_set / unordered_map**，因为它们是哈希表结构，效率最高   



## 6. **哈希法的使用场景总结**
当你需要：

- **快速判断某元素是否出现过**  
- **快速查找是否存在某 key**

第一时间应该想到哈希法 

但哈希法是 **空间换时间**：需要额外的数组 / set / map 来存储数据 


## 📌 **一句话总结**
> **哈希表 = 用哈希函数把 key 映射到数组下标，通过 O(1) 查找实现高效判断与搜索；碰撞用拉链法或线性探测法解决；C++ 中 unordered_set / unordered_map 是最常用的哈希结构。**
